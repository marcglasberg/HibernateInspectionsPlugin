Reports classes marked with @Entity, @MappedSuperclass or @Embeddable that are final.

To load data only when it's needed ("lazy loading"), Hibernate creates a subclass of your class, called a proxy. It can't create a subclass of a final class. Your code still works, but Hibernate can't load this class lazily, which can make your app slower.

Example:


@Entity
public final class Cat { ... }   // Warning

How to fix it: remove final from the class. The quick-fix does this for you. If you really want the class to be final, you can turn off proxies for it with @Proxy(lazy=false) (deprecated since Hibernate 6.2, and removed in Hibernate 7).

Records are not reported. Only classes that use annotations are checked, not XML mappings. Works with jakarta.persistence and javax.persistence annotations.

More information: Hibernate documentation, Stack Overflow question.
