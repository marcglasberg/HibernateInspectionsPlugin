Reports @Embeddable classes that extend another @Embeddable class, when the project uses a Hibernate version older than 6.6.

Before version 6.6, Hibernate doesn't support this. It saves only the fields declared in the exact class used in the entity, not the fields of its parent class. Also, when loading the entity, Hibernate may silently set the whole embedded object to null.

Example:


@Embeddable
public class Address { ... }

@Embeddable
public class HomeAddress extends Address { ... }   // Warning

How to fix it: don't extend one @Embeddable class from another (for example, copy the fields into the subclass), or upgrade to Hibernate 6.6 or newer.

Hibernate 6.6 and newer support this. If your project uses Hibernate 6.6 or newer, this warning is not shown.

More information: Hibernate issues HHH-1152, HHH-1910 and HHH-3455; Stack Overflow questions 1, 2 and 3.
